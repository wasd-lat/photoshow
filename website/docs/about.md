# Sobre este caderno

O PhotoShow cresceu por várias ondas técnicas e uma migração de toolkit
(egui → Freya). Existem boas decisões e algoritmos que devem ser preservados,
mas também sobreposição de responsabilidades e um documento monolítico de
engenharia que precisa ser quebrado em domínios.

Este caderno separa explicitamente:

- estado atual comprovado;
- problemas observados;
- propostas em discussão;
- decisões aprovadas.

Nenhuma proposta vira arquitetura final automaticamente.
